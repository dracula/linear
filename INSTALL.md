### [Linear](https://linear.app)

#### Install manually

Copy the JSON theme below :

```json
{
  "base": [17.252408696973347, 8.237902839754266, 280.68438413225124, 1],
  "accent": [68.00695951923818, 55.297268582341914, 304.5242065902371, 1],
  "contrast": 30,
  "sidebar": {
    "accent": [61.05628644357074, 75.568472055974, 30.319379622932082, 1],
    "base": [
      30.45557788323979, 11.983447878726658, 281.10721783109096,
      0.4392156862745098
    ],
    "contrast": 30
  }
}
```

#### Activating theme

1. Go to `Settings (G then S) -> Preferences`
2. Under `Interface and Theme` -> `Sharing`
3. Click `Import Theme`. Paste in the JSON, Boom! Working! 🎉
